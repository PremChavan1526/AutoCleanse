Fix it automatically

Questions, answered plainly.

What kind of data does it handle?

Tabular data in CSV files, prepared for classification and regression problems. Text, images and time series are outside the current scope.

Does it change my original file?

No. AutoCleanse writes a cleaned copy and a decision log. Your upload stays exactly as it was.

How is this different from AutoML?

AutoML picks and tunes a model. AutoCleanse stops earlier: it prepares the data and shows its reasoning, so you can check the data before you train.

How is the readiness score worked out?

It combines completeness, consistency, class balance, outlier load and feature quality, measured before and after cleaning. A baseline model trained on both versions checks that the score reflects real improvement.

Can I override a decision?

Yes. Every method in the settings can be set by hand. Auto is only the default.
